# Chai Culture - Coming Soon Landing Page

![Chai Culture](https://img.shields.io/badge/Chai%20Culture-Brew%20the%20Royal%20Tradition-D4AF37?style=for-the-badge)

A premium "Coming Soon" landing page for **Chai Culture** - an instant chai tea premix brand inspired by royal Indian households.

## 🔗 Live Demo

**[View Live Site](https://meet1785.github.io/ChaiCultureAss/)**

## 🎨 Design Choices

The design draws inspiration from **royal Indian aesthetics** with a warm, inviting color palette of **golds (#D4AF37), deep browns (#3E2723), and creams (#FDF5E6)** to evoke the richness of traditional chai. Typography pairs the elegant **Cormorant Garamond** serif for headings with clean **Poppins** for body text, balancing heritage with modernity. Subtle animations like steam wisps, gold shimmer effects on the "Launching Soon" badge, and decorative corner ornaments create an immersive, premium brand experience while maintaining fast load times and accessibility.

## ✨ Features

- **Responsive Design** - Fully optimized for mobile, tablet, and desktop
- **Email Signup** - Functional email capture with validation and success feedback
- **Elegant Animations** - Subtle CSS animations including steam effects and shimmer
- **Dark Mode Support** - Automatic dark theme based on user preference
- **Accessibility** - ARIA labels, reduced motion support, semantic HTML
- **Clean Code** - Well-organized CSS with custom properties, modular JavaScript

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, Flexbox, animations, media queries
- **JavaScript** - Vanilla JS with modern ES6+ features
- **Fonts** - Google Fonts (Cormorant Garamond, Poppins)
- **Icons** - Font Awesome 6

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/meet1785/ChaiCultureAss.git
   ```

2. Open `index.html` in your browser, or use a local server:
   ```bash
   npx serve .
   ```

3. To add your logo, replace `logo.png` in the root directory.
